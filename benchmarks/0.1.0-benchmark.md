## Notes

- Popup render cost is nearly flat from 10 → 500 suggestions: only visible
  rows (`max_visible`, default 10) are rendered regardless of total count.
- Ghostty and iTerm2 profiles are within noise of each other; the profile
  difference is capability metadata, not a divergent render path.
- A full overlay update frame (~7 µs) is well under a 16 ms frame budget at
  60 Hz.
- Parser throughput on plain text is ~358 MB/s (64 KB / 179.7 µs); ANSI and
  cursor-heavy inputs trade ~20–35% for escape processing.
- Criterion HTML reports: `target/criterion/report/index.html`.
